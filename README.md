## 🛡 Security and Safety

The software performs all operations locally on your machine. The automatic update feature ensures you always use the latest version without manual downloads. If your antivirus program flags the file, this happens because the software interacts with another game process. You may need to add an exclusion in your Windows Security settings to allow the program to run.

To add an exclusion:
1. Open Windows Security.
2. Go to Virus and threat protection.
3. Select Manage settings.
4. Scroll to Exclusions and click Add or remove exclusions.
5. Select the folder where you saved the application.
